# BRIEF.md

## 1. Project Summary

**Jullien Lab** is a minimal, cyber-space portfolio site for Jullien, Founder of Human+.

The site presents AI systems, AI agents, Web app development, practical automation, and selected portfolio Work.

The design has been changed from a service-heavy portfolio to a more immersive single-page lab experience.

---

## 2. Primary Goals

```txt
1. Create a memorable portfolio experience.
2. Communicate technical depth without overexplaining on the top page.
3. Let visitors ask about Jullien through an AI terminal.
4. Show Work visually through 3D project objects.
5. Keep contact routes simple.
```

## 7. Key Experience Decisions

### Jullien Lab Section

Only `Jullien Lab` appears as the main visible text. The background contains a monochrome interactive graphical 3D earth.

### Terminal Section

A terminal UI allows visitors to ask an AI about Jullien's background, Work, skills, and contact routes.

### About me Section

A circular profile photo and short personal copy humanize the portfolio.

### Work Section

Work cards use 3D objects derived from each project. Default state shows only the object and project name. Hover/focus reveals a compact popup.

### Skill Stack Section

Three pentagon diagrams show practical skill areas. Broader technologies are linked through StackShare.

### Contact me Section

Email, X, and GitHub only. No form.

---

## 8. Business Positioning

The site should not look like a typical agency landing page. It should feel like a personal lab with enough clarity to lead to freelance inquiries.

The terminal and Work detail pages provide depth. The top page stays minimal.
