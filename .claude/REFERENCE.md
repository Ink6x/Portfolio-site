# REFERENCE.md

## 1. Purpose

This document records the design references and interpretation for the redesigned **Jullien Lab** site.

The current direction replaces the earlier astronaut-card hero with a more minimal, monochrome, cyber-space interface.

---

## 2. Current Design Direction

```txt
minimal
space
cyber
trust
monochrome
interactive earth
terminal UI
3D project objects
pentagon skill diagrams
```

---

## 3. Top Section Reference Interpretation

The top section should not act like a sales hero.

It should feel like entering a digital lab:

```txt
- only Jullien Lab as main text
- monochrome 3D earth
- large negative space
- quiet movement
- no CTA
- no explanatory text
```

Avoid:

```txt
- hero copy blocks
- service lists
- bright gradients
- full marketing layout
```

---

## 4. Terminal Reference Interpretation

The terminal should reference real terminal emulator aesthetics, not fake hacking visuals.

Use:

```txt
- terminal window frame
- command prompt
- monospace font
- frosted glass background
- command history
- keyboard interaction
```

Avoid:

```txt
- matrix rain
- green hacker cliche if cheap
- too many scanlines
- unreadable pixel fonts
```

---

## 5. Work Card Reference Interpretation

Work cards should be minimal and object-led.

Use:

```txt
- one 3D symbolic object
- project name
- hover/focus motion
- compact popup
- click to detail page
```

Avoid:

```txt
- text-heavy portfolio cards
- SaaS feature cards
- screenshots as the only visual
- colorful game collectible cards
```

---

## 6. Skill Diagram Reference Interpretation

Use pentagon/radar diagrams for skill groups.

Rules:

```txt
- three diagrams on desktop
- monochrome
- minimal labels
- no colorful chart palette
- text summary for accessibility
```

---

## 7. Typography Reference

Menu and small labels should use Misaki Gothic or similar bitmap/pixel Japanese style.

Terminal uses a real terminal-style monospace font.

Body text remains readable and modern.
